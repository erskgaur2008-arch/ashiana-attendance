# Push notifications — implementation notes

This feature branch is additive and is not deployed.

## Existing configuration reviewed
- Website uses `sw.js` and GitHub Pages.
- Android APKs are generated by `.github/workflows/android-apk.yml` through Capacitor 8.
- Admin/teacher/staff use Supabase Auth; student login is RPC-based and does not share a persistent Supabase Auth session.

## Required setup before delivery can be enabled
- Generate Web Push VAPID keys and set `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, and `VAPID_SUBJECT` as Supabase Edge Function secrets.
- Configure a Firebase project and Android app configuration for FCM. Never commit service-account credentials or Firebase private keys.
- Add a trusted registration path for RPC-based student sessions before students can safely register devices.
- Connect notice publication, leave decisions, homework/timetable updates, and attendance updates to trusted server-side dispatchers. Ordinary clients must not be able to send notifications to arbitrary users.

## Safe rollout
1. Review the SQL migration and apply to a test Supabase project only.
2. Deploy Edge Functions to test only after configuring secrets.
3. Test each role, web/PWA subscription, Android permission/token lifecycle, logout, and event targeting.
4. Do not merge or deploy to production until approved.

No production migration, deployment, or user-data modification has been performed.

# EduPunch — Ashiana Public School

This package is the modified version of the original Ashiana attendance `index.html` project, prepared for static hosting on GitHub Pages.

## What is connected

- Supabase Auth for administrator and staff sessions.
- Staff access is limited by Supabase RLS to the signed-in staff member's records.
- Staff sign-in uses registered staff email + 4-digit PIN.
- Attendance requires scanning the active school QR and then entering the 4-digit PIN.
- QR sessions are generated by the Supabase `generate-attendance-qr` Edge Function and expire after 60 seconds.
- Attendance is recorded by the `verify-attendance` Edge Function.
- Admin QR station automatically refreshes its secure QR session while the QR tab is open.
- PINs are stored as bcrypt hashes in Supabase; the browser no longer stores plaintext PINs.
- The old hardcoded `admin123` login and demo `1234` PINs have been removed from the frontend.
- The school logo reference has been corrected to `logo 2.png`.
- No service-role or secret Supabase key is included in the frontend.

## GitHub Pages

Put `index.html` and `logo 2.png` in the root of the GitHub repository.

GitHub → Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Supabase Auth setup

1. Create/confirm the administrator Auth account for the email configured in `public.admin_users`.
2. The current admin email configured in the database is `rajkumargaur54@gmail.com`.
3. Because that email also exists as a staff record, use it through the Administrator login, not the Staff login. Set the administrator Auth password in Supabase Auth before first use.
4. The existing staff roster has Auth accounts provisioned for the current 72 staff records.
5. Existing staff sign in with their registered email and their current 4-digit attendance PIN.

## Important for new staff

When adding/importing new staff, create/provision their Supabase Auth account with the same registered email and attendance PIN. The staff table PIN is hashed server-side; do not put plaintext PINs into the frontend source or repository.

## GitHub Pages URL

After publishing, add the final GitHub Pages URL to Supabase Authentication URL Configuration as the Site URL / allowed redirect URL where appropriate.
